# Neno SACCO Finance Workspace

A responsive Next.js dashboard concept for SACCO operations: member records, savings, lending, dividends, payments, employees, reports, and workspace settings.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Run `npm run typecheck` and `npm run build` to validate the application.

## Demo scope

The workspace uses sample data. Navigation, search, summary views, and add-record dialogs work in the browser, but changes are not persisted. Authentication, member and employee accounts, payment processing, and dividend disbursements are not connected to production services; those require a configured backend, identity provider, and payment integrations.
